Core Data Structures & Algorithms Benchmark and Visualization Engine in Python.

## Included Algorithms
- **Sorting:** QuickSort, MergeSort ($O(N \log N)$).
- **Graphs:** Dijkstra Shortest Path ($O((V + E) \log V)$), BFS traversal.
- **Dynamic Programming:** 0/1 Knapsack, Longest Common Subsequence.
